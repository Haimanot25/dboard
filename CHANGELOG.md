# Changelog

All notable changes to DBoard will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-08-02

### Added
- Multi-database support (PostgreSQL, MySQL, SQLite, MongoDB, Supabase, SQL Server)
- Unified dashboard with chart widgets and drag-and-drop layout
- SQL query editor with syntax highlighting and format SQL
- Saved queries and query history
- AI-powered query generation and insights
- Schema management with introspection and diff
- Data import/export (CSV, Excel, JSON)
- Role-based access control with user management
- API key authentication
- Webhook integrations
- Custom admin pages with configurable tables
- Dashboard templates
- Dashboard sharing with permission levels
- Activity feed and audit logging
- Notification preferences
- Backup and restore (JSON export/import)
- Command palette (Cmd+K)
- Keyboard shortcuts
- Database monitoring with real-time metrics
- Connection health monitoring with latency tracking
- Dark mode support
- Docker support with multi-stage build
- CI/CD pipeline with GitHub Actions
- Rate limiting and CSRF protection
- SSRF protection for database connections
- Encrypted credential storage (AES-256-GCM)
